# 🎬 Netflix Titles Data Analysis using Python

## 📌 Project Overview

This project analyzes the Netflix Titles dataset using Python and Jupyter Notebook. I performed data cleaning, exploratory data analysis (EDA), and visualizations to understand content trends on Netflix.

## 🛠️ Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## 📊 Analysis Performed

* Checked missing values
* Removed duplicate records
* Movies vs TV Shows analysis
* Release year trend analysis
* Top countries producing Netflix content
* Genre analysis using visualizations

## 📁 Project Files

* `Netflix_Analysis.ipynb`
* `netflix_titles.csv`

## 🎯 Skills Gained

* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Python Programming
